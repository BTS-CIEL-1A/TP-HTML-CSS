## Présentation

Ce site pédagogique permet de découvrir les principales notions du développement Web côté interface. Les contenus sont organisés en accordéons pour consulter les explications, les exemples de code HTML et CSS et leur résultat dans le navigateur.

## Contenu du site

- **Accueil** : historique du Web.
- **Doctype** : structure d'un document HTML5.
- **HTML** : balises sémantiques, contenus, listes, tableaux, images, liens et formulaires.
- **CSS** : sélecteurs, propriétés du texte, couleurs, modèle de boîte et styles.
- **Mise en page** : `block`, `inline`, `inline-block`, positionnement, `z-index`, `float` et Flexbox.
- **Responsive** : adaptation aux écrans d'ordinateur, de tablette et de smartphone.
- **TP** : mise en pratique des notions étudiées.

## Fonctionnalités

- Menu de navigation responsive avec bouton hamburger.
- Cours présentés sous forme d'accordéons.
- Exemples de code avec bouton de copie.
- Captures d'écran agrandissables au clic.
- Liens vers des ressources de documentation et de validation W3C.

## Technologies utilisées

- **HTML5** pour la structure des pages.
- **CSS3** pour la présentation et l'adaptation aux écrans.
- **JavaScript** pour les interactions (menu, accordéons et autres fonctions du site, selon leur implémentation).
- **Visual Studio Code** comme éditeur de code.
